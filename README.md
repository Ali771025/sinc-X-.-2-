# Sinc-squared Spectral Density

MATLAB sinc-squared spectral-density plots for two symbol-probability values.

## Overview

Two plots compare a sinc-squared spectral-density expression at symbol probabilities `p = 0.1` and `p = 0.5`, including a discrete element at zero frequency.

## Requirements

MATLAB and Signal Processing Toolbox (`sinc`).

## Getting started

Clone this repository and open its directory:

```bash
git clone https://github.com/Ali771025/sinc-X-.-2-.git
cd sinc-X-.-2-
```

Run the example from that directory:

```matlab
run('sinc(X).^2 .m')
```

## Compatibility and scope

The impulse-like term is represented by one nonzero sample in a finite array. Interpret this as a sampled illustration rather than a continuous spectral impulse with normalized area.
